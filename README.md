# 🚪 Gizemli Kapılar (Mysterious Doors)

DevOps dersi için geliştirilmiş 3 aşamalı interaktif bulmaca oyunu.

## 🛠️ Teknolojiler
- **Backend:** Python (Flask)
- **Frontend:** HTML5, CSS3, JavaScript
- **DevOps:** Git, GitHub, Pytest, Docker

## 🚀 Çalıştırma Adımları
1. Projeyi klonlayın: `git clone <repository-url>`
2. Bağımlılıkları yükleyin: `pip install flask`
3. Uygulamayı başlatın: `python app.py`
4. Tarayıcıda açın: `http://localhost:5000`
